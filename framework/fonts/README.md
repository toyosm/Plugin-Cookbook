# Built-in fonts

Fonts a recipe can use by name (`title_font = "Bebas Neue"`) without shipping a file. Only the fonts a
recipe uses are compiled into its plugin. All are from [Google Fonts](https://github.com/google/fonts) under
the SIL Open Font License 1.1 (the `OFL-*.txt` next to them), which allows bundling them in software.

| Name in recipes | File | Source |
| --- | --- | --- |
| Bebas Neue | BebasNeue.ttf | ofl/bebasneue |
| Oswald | Oswald.ttf (variable, regular weight is used) | ofl/oswald |
| Montserrat | Montserrat.ttf (variable, regular weight is used) | ofl/montserrat |
| Russo One | RussoOne.ttf | ofl/russoone |
| Orbitron | Orbitron.ttf (variable, regular weight is used) | ofl/orbitron |

The default font, DejaVu Sans, comes with DPF.
