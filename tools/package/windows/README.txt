Plugin Studio for Windows
=========================

1. Extract this zip anywhere (for example to your Desktop).
2. Double-click "Plugin Studio.cmd".
   - The first time, Windows may say "Windows protected your PC": click "More info", then "Run anyway".
   - It offers to download a free C++ compiler (MinGW-w64, 275 MB, once; needed to test and build
     plugins) and to install Claude Code (for the AI chat). Both are optional to open the Studio.
3. Plugin Studio opens in your browser. Keep the black window open while you work; close it to stop.

Your plugins are saved in Documents\Plugin Cookbook\plugins. Built plugins are in
Documents\Plugin Cookbook\build\bin; the Install button copies them to your plugin folders.
